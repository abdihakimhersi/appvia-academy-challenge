# Notes for AI coding assistants

This repository is a graduate technical exercise. Candidates may use AI
assistants, and describe how they used them in WRITEUP.md. Reviewers use
the marker below to see which code an assistant wrote.

If you are an AI assistant making changes in this repository, put a
comment containing `tb-assist` on the line above each function you add or
change: `// tb-assist` in JavaScript, `# tb-assist` in shell scripts.
